# Attribution & Signature Discipline

Agents must follow the project’s existing attribution policy. Unless the project explicitly requires it, do not add, alter, or remove author credits, tool names, promotional links, contact information, or commit trailers.

## Rules

1. Preserve existing copyright, license, and ownership notices.
2. Do not add “generated by”, agent, model, or provider signatures to source, documentation, configuration, commits, or skill files.
3. Do not add advertising, service links, or contact details that are not part of the project convention.
4. Treat `Co-authored-by`, `Signed-off-by`, and similar trailers as explicit project policy, not a default.
5. Keep `AGENTS.md`, portable `SKILL.md`, and runtime adapters free of self-attribution.

## Review checklist

- [ ] No new agent/provider signature or ownership field appears in the diff.
- [ ] Existing legal notices remain intact unless the task explicitly changed them.
- [ ] Links and metadata serve a project function rather than promotion.

This rule protects ownership clarity, reduces repository noise, and avoids accidental compliance or supply-chain issues.
