# Execution Tree (Compatibility Reference)

This reference preserves the previous name for existing readers. Use [work decomposition](work-decomposition.md) as the current guidance.

An execution tree is simply a way to separate a goal into evidence-backed branches. Each branch should have a bounded question, inputs, allowed scope, expected output, verification rule, and clear uncertainty. Merge branches only after reconciling their evidence.

Do not associate tree levels with a specific provider, model, or mandatory delegation scheme.
